# Dimitris Gallinios – Portfolio

Προσωπικό portfolio με όλα τα projects μου.

## Χαρακτηριστικά

- Λίστα projects με φίλτρο ανά τεχνολογία
- Η παλέτα χρωμάτων κάθε project εμφανίζεται δίπλα στον τίτλο
- Σταθερή στήλη με στοιχεία και συνδέσμους
- Light / dark mode, responsive

## Τεχνολογίες

HTML, CSS και JavaScript χωρίς frameworks, σε ένα αρχείο. Γραμματοσειρές από Google Fonts.

## Εκτέλεση

Άνοιξε το `index.html` σε οποιονδήποτε browser.
